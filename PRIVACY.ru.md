# Политика конфиденциальности WinNetSwitch

[English](PRIVACY.md) | **Русский**

WinNetSwitch и его плагин Stream Deck работают локально на Windows-компьютере пользователя. В них нет аналитики, рекламы, телеметрии, пользовательских аккаунтов или сетевого сервиса, управляемого проектом.

## Локальная обработка данных

Companion-приложение WinNetSwitch читает следующие сведения о сетевых адаптерах Windows, чтобы показывать и менять их состояние:

- отображаемое имя и описание адаптера, идентификатор интерфейса, статус и состояние включения;
- Plug and Play identifier, когда Windows требует его для повторного включения отключённого физического адаптера;
- состояние программного и аппаратного Wi-Fi radio.

Плагин Stream Deck получает через local named pipe, ограниченный текущим интерактивным Windows logon-сеансом, лишь идентификатор, отображаемое имя, описание, статус, состояния enabled/active и wireless flag. Stream Deck сохраняет идентификатор адаптера, выбранного для команды `Adapter On/Off`, как локальную настройку этой команды.

## Логи

WinNetSwitch записывает локальные диагностические логи в `%LOCALAPPDATA%\WinNetSwitch\logs`. Они могут содержать имена адаптеров, идентификаторы интерфейсов, результаты операций и сообщения Windows об ошибках. При достижении 1 MiB лог ротируется. Перед публикацией лога просмотрите его и удалите персональные и специфичные для окружения сведения.

Stream Deck SDK может создавать собственные локальные логи плагина в хранилище Stream Deck. WinNetSwitch эти логи не передаёт.

## Сетевой доступ

Обычное управление адаптерами использует локальные Windows API, Windows PowerShell и локальное межпроцессное взаимодействие. WinNetSwitch и плагин не отправляют сведения об адаптерах авторам проекта или третьим лицам.

Плагин открывает GitHub только когда пользователь явно нажимает Download, Support или help-ссылку из manifest. После этого GitHub обрабатывает запрос по собственной политике конфиденциальности.

## Удаление и поддержка

Деинсталлятор WinNetSwitch удаляет приложение и его диагностические данные. Установкой плагина и настройками команд управляет Stream Deck; удалите плагин и его команды через Stream Deck, чтобы прекратить их использование.

Вопрос о конфиденциальности можно задать через [поддержку WinNetSwitch](https://github.com/witqq/win-net-switch/issues). Не включайте приватные сведения о сети в публичную Issue.
